#### 2.1 修改 `updateService.darwin.ts` (macOS)

**文件**: `src/vs/platform/update/electron-main/updateService.darwin.ts`

**修改点**:

```typescript
protected buildUpdateFeedUrl(quality: string): string | undefined {
    // 复用现有的 zhikai.auth.apiUrl 配置
    const apiUrl = this.configurationService.getValue<string>('zhikai.auth.apiUrl');
    if (!apiUrl) {
        this.logService.warn('未配置 zhikai.auth.apiUrl，自动更新功能不可用');
        return undefined;
    }

    // 获取平台类型
    const platform = process.platform === 'darwin' ? 'mac' : 'windows';

    // 构建完整的更新检查 URL
    // 格式: http://192.168.1.100:8088/knowledge/plugin/update-check?platform=mac&version=1.106.0
    const currentVersion = this.productService.version;
    const checkUrl = `${apiUrl.replace(/\/$/, '')}/knowledge/plugin/update-check?platform=${platform}&version=${currentVersion}`;

    this.logService.info(`[Update] 检查更新: ${checkUrl}`);

    return checkUrl;
}

// 重写下载逻辑
protected async downloadUpdate(update: IUpdate): Promise<void> {
    const downloadUrl = update.url;
    this.logService.info(`开始下载更新: ${downloadUrl}`);

    // 使用内置 requestService 下载文件
    const response = await this.requestService.request({ url: downloadUrl }, CancellationToken.None);

    // 保存到临时目录
    const tempPath = path.join(os.tmpdir(), 'maxian-update.zip');
    await fs.promises.writeFile(tempPath, response.stream);

    this.logService.info(`更新文件已下载到: ${tempPath}`);

    // 触发安装
    this.setState(State.Downloaded({
        version: update.version,
        productVersion: update.productVersion
    }));
}
```

### 步骤 3: 后端API扩展

#### 3.1 新增更新检查接口

**文件**: `PluginVersionController.java`

**新增方法**:

```java
/**
 * IDE更新检查接口
 *
 * @param platform 平台类型: windows | mac
 * @param version 当前版本号
 * @return 更新信息（如果有可用更新）
 */
@GetMapping("/update-check")
public R<UpdateCheckResponse> checkUpdate(
    @RequestParam String platform,
    @RequestParam String version) {

    try {
        // 获取该平台的最新版本
        PluginVersionVo latest = pluginVersionService.getLatestVersionByPlatform(platform);

        if (latest == null) {
            return R.ok(null, "暂无可用版本");
        }

        // 比较版本号
        if (compareVersion(version, latest.getVersionNumber()) >= 0) {
            // 当前已是最新版本
            return R.ok(null, "已是最新版本");
        }

        // 构建更新响应
        UpdateCheckResponse response = new UpdateCheckResponse();
        response.setVersion(latest.getVersionNumber());
        response.setUrl(buildDownloadUrl(latest.getId()));
        response.setReleaseNotes(latest.getReleaseNotes());
        response.setFileSize(latest.getFileSize());
        response.setReleaseDate(latest.getCreateTime());

        log.info("检查更新: platform={}, currentVersion={}, latestVersion={}",
            platform, version, latest.getVersionNumber());

        return R.ok(response, "发现新版本");

    } catch (Exception e) {
        log.error("更新检查失败", e);
        return R.fail("更新检查失败: " + e.getMessage());
    }
}

/**
 * 构建下载URL
 */
private String buildDownloadUrl(Long versionId) {
    // 假设服务器地址从配置读取
    String serverUrl = "http://192.168.1.100:8088";
    return serverUrl + "/knowledge/plugin/download/" + versionId;
}

/**
 * 版本号比较
 * @return >0 表示 v1 > v2, <0 表示 v1 < v2, 0 表示相等
 */
private int compareVersion(String v1, String v2) {
    String[] parts1 = v1.split("\\.");
    String[] parts2 = v2.split("\\.");

    int len = Math.max(parts1.length, parts2.length);
    for (int i = 0; i < len; i++) {
        int num1 = i < parts1.length ? Integer.parseInt(parts1[i]) : 0;
        int num2 = i < parts2.length ? Integer.parseInt(parts2[i]) : 0;
        if (num1 != num2) {
            return num1 - num2;
        }
    }
    return 0;
}
```

#### 3.2 新增文件下载接口

```java
/**
 * 下载插件文件
 */
@GetMapping("/download/{id}")
public void downloadPlugin(
    @PathVariable Long id,
    HttpServletResponse response) throws IOException {

    try {
        PluginVersionVo version = pluginVersionService.queryById(id);

        if (version == null || !"1".equals(version.getStatus())) {
            response.sendError(HttpServletResponse.SC_NOT_FOUND, "文件不存在或已下架");
            return;
        }

        File file = new File(version.getFilePath());
        if (!file.exists()) {
            response.sendError(HttpServletResponse.SC_NOT_FOUND, "文件不存在");
            return;
        }

        // 记录下载次数
        pluginVersionService.incrementDownloadCount(id);

        // 设置响应头
        response.setContentType("application/octet-stream");
        response.setHeader("Content-Disposition",
            "attachment; filename=\"" + version.getFileName() + "\"");
        response.setContentLengthLong(file.length());

        // 传输文件
        try (FileInputStream fis = new FileInputStream(file);
             ServletOutputStream out = response.getOutputStream()) {

            byte[] buffer = new byte[8192];
            int bytesRead;
            while ((bytesRead = fis.read(buffer)) != -1) {
                out.write(buffer, 0, bytesRead);
            }
            out.flush();
        }

        log.info("文件下载成功: id={}, file={}", id, version.getFileName());

    } catch (Exception e) {
        log.error("文件下载失败", e);
        response.sendError(HttpServletResponse.SC_INTERNAL_SERVER_ERROR,
            "下载失败: " + e.getMessage());
    }
}
```

## 🚀 使用流程

### 管理员上传新版本

1. 登录管理后台
2. 进入 **插件版本管理** 页面
3. 点击 **上传新版本**
4. 选择类型: IDE
5. 选择平台: Windows 或 Mac
6. 输入版本号: 如 `1.107.0`
7. 填写更新说明
8. 上传 .zip 文件
9. 勾选 "设为最新" ✓
10. 点击上传

### IDE 自动检查更新

IDE 会在以下时机检查更新:

1. **启动时自动检查** (后台静默)
2. **用户手动检查**: 菜单 → 帮助 → 检查更新
3. **定时检查**: 每24小时检查一次

**检查流程**:
1. IDE 请求: `GET http://192.168.1.100:8088/knowledge/plugin/update-check?platform=windows&version=1.106.0`
2. 后端返回:
   - 无更新: `{ code: 200, data: null, msg: "已是最新版本" }`
   - 有更新:
   ```json
   {
     "code": 200,
     "data": {
       "version": "1.107.0",
       "url": "http://192.168.1.100:8088/knowledge/plugin/download/123",
       "releaseNotes": "修复若干问题",
       "fileSize": 104857600,
       "releaseDate": "2025-12-13T10:00:00"
     },
     "msg": "发现新版本"
   }
   ```
3. IDE 显示更新提示
4. 用户点击 "下载并安装"
5. IDE 下载文件到临时目录
6. IDE 提示重启应用更新

## 🔒 安全考虑

### 1. 文件完整性校验

虽然是内网环境，但仍建议添加文件完整性校验:

**后端生成SHA256**:
```java
private String calculateSHA256(File file) throws Exception {
    MessageDigest digest = MessageDigest.getInstance("SHA-256");
    try (FileInputStream fis = new FileInputStream(file)) {
        byte[] buffer = new byte[8192];
        int bytesRead;
        while ((bytesRead = fis.read(buffer)) != -1) {
            digest.update(buffer, 0, bytesRead);
        }
    }
    return bytesToHex(digest.digest());
}
```

**IDE 下载后验证**:
```typescript
async function verifySHA256(filePath: string, expectedHash: string): Promise<boolean> {
    const crypto = require('crypto');
    const fs = require('fs');

    return new Promise((resolve, reject) => {
        const hash = crypto.createHash('sha256');
        const stream = fs.createReadStream(filePath);

        stream.on('data', data => hash.update(data));
        stream.on('end', () => {
            const actualHash = hash.digest('hex');
            resolve(actualHash === expectedHash);
        });
        stream.on('error', reject);
    });
}
```

### 2. 版本号校验

防止版本降级攻击:
```java
if (compareVersion(currentVersion, targetVersion) > 0) {
    throw new BusinessException("不允许降级到旧版本");
}
```

## 🐛 故障处理

### 1. 更新检查失败

**问题**: IDE 无法连接到更新服务器

**排查步骤**:
1. 检查 IDE 日志: `~/.maxian/logs/main.log`
2. 验证网络连通性: `ping 192.168.1.100`
3. 测试更新API: `curl http://192.168.1.100:8088/knowledge/plugin/update-check?platform=windows&version=1.0.0`
4. 检查后端日志

### 2. 下载失败

**问题**: 下载中断或文件损坏

**解决方案**:
- 添加断点续传支持（HTTP Range 请求）
- 增加重试机制（最多3次）
- 显示下载进度

### 3. 安装失败

**问题**: 下载成功但无法安装

**排查**:
1. 检查文件权限
2. 验证 ZIP 文件完整性
3. 查看 Electron 日志

## 🎯 优化建议

### 1. 增量更新（可选）

如果文件很大（>500MB），考虑增量更新:
- 只下载变化的文件
- 使用 `bsdiff` 算法生成差分包
- 节省带宽和下载时间

### 2. P2P 分发（可选）

内网环境下，可以利用已更新的客户端:
- 支持客户端之间互相分享更新文件
- 减轻服务器压力
- 加快下载速度

### 3. 灰度发布

通过后端控制:
```java
// 只对20%的用户推送更新
if (shouldReceiveUpdate(userId)) {
    return latestVersion;
} else {
    return null; // 暂不推送
}
```
